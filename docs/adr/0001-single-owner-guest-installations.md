# Keep guest hosting separate by installation

Each companion installation serves one installation owner. A host administrator can operate separate guest installations on the same hardware, each with independent credentials and data. This keeps the single-user model and limits accidental sharing without introducing a shared multi-account application.

The host administrator remains trusted with access to each installation's Plex credentials and library metadata. Separate installations do not protect guests from the administrator of the machine. The owner accepted this boundary during the open-source release interview on 2026-09-07.
