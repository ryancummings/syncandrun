SyncAndRun Companion · First run

Choose a home LAN address

Your watch and browser will use this address to reach the companion. Give this computer a static DHCP lease so the address stays the same.

LAN HTTP is unencrypted. Anyone able to observe traffic on this network may intercept setup links, browser sessions, watch credentials, and media. Use only a trusted private LAN. Do not forward router ports.

Changing the saved address requires watch re-pairing. Cached audio remains on the watch.

Allow inbound TCP 31415 only from your home LAN in the host firewall. The Node companion itself stays on loopback.
